About the mcpdrift crawler

What it does

mcpdrift watches public MCP servers for changes to their tool schemas, so that teams whose agents depend on those tools find out when the contract moves.

The crawler identifies itself as:

User-Agent: mcpdrift/0.1 (+http://mcpdrift.dev/bot)

What it requests

Discovery methods only, over HTTP:

  • initialize
  • tools/list
  • resources/list
  • prompts/list

It never calls tools/call. No tool on a monitored server is ever invoked. This is not a policy we remember to follow: the client object mcpdrift uses has no method capable of invoking a tool, so doing it would take a deliberate code change rather than a slip.

It reads only what the server publishes to any unauthenticated client. It does not authenticate, does not attempt to discover private servers, and does not probe anything outside the four methods above.

Rate

One poll per server per day by default. Each server's poll time is derived from its own identifier, so requests are spread across the day rather than issued on the hour, and it polls at the same time each day rather than drifting. Concurrency is limited to one request at a time per host.

No conditional-request mechanism is used: MCP discovery is a JSON-RPC POST, and HTTP entity tags do not meaningfully apply to it. If a way to skip unchanged manifests at the transport layer becomes available, this page will say so once the code does it, not before.

Opting out

Mail opt-out@mcpdrift.dev with your server's endpoint and it stops being polled. No justification needed and no reply required to take effect.

Corrections

Every published item links the evidence it was derived from. If an item is wrong, mail corrections@mcpdrift.dev and it will be corrected or withdrawn.

Known limits

The false-positive sources this system knows about, and what it does about each, are maintained in the repository. They are not yet published: no public surface exists until mcpdrift has measured how often MCP servers actually break, and a limitations page is still a public surface. Mail corrections@mcpdrift.dev and the current list will be sent to you.

It is maintained as a list of things that are wrong with the detector, not as marketing.
